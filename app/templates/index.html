💻 Windows Integration

                    

                    
    
                        
  • Windows Defender Integration: Direct CLI verification via MpCmdRun.exe when available.
    • 
                        
  • Ephemeral Staging: Temporary chroot-isolated analysis folders destroyed upon sandbox teardown.
    • 
                        
  • Egress Boundary: Anti-SSRF blocking of private subnets (RFC1918) and cloud metadata services.
    • 
                        
  • Capabilities vs Limits: Guard AI does not replace kernel-level drivers; it provides application-layer orchestration and static sandbox isolation.
    • 
                    

                


                

                    

                        
📱 Android Architecture

                    

                    
    
                        
  • Sandboxed UID: Linux per-app UID isolation limits cross-app memory and storage access.
    • 
                        
  • Hardware Keystore: AndroidKeyStore hardware-backed key protection for AES-GCM and Ed25519 primitives.
    • 
                        
  • Accessibility / VPN Limits: Full URL inspection requires user-consented Accessibility Service or local VpnService loopback.
    • 
                        
  • Compliance Note: An ordinary Android app cannot inspect arbitrary private storage without root or enterprise MDM.
    •
